# Release Notes и Changelog

## Release Notes

### Мобильное приложение, версия X.Y.Z — 30.10.2025

**Платформы:** iOS, Android

#### Новое: таймлапс в мобильном приложении

Теперь вы можете создавать и скачивать таймлапсы прямо в мобильном приложении — без перехода в веб-версию. Таймлапс сжимает многочасовую запись камеры в короткий ролик, чтобы быстро просмотреть, что происходило за день.

**Как открыть:** «Настройки» → «Таймлапс».

**Как это работает:**

1. Нажмите «Создать таймлапс».
2. Выберите камеру-источник и настройки записи.
3. Нажмите «Готово».

Если на камере есть архив, таймлапс будет создан почти сразу. Если настроено расписание, таймлапс будет формироваться с заданным интервалом.

**Ограничения:** доступно при подключённой услуге «Таймлапс» и наличии архива.

### Веб-клиент — 24.10.2025

#### Новое: раздел «Объекты»

Теперь камеры можно объединять в объекты — например, по адресу или назначению. Для объекта можно задать общие свойства и выдать доступ сразу ко всем его камерам. Доступны два типа объектов: универсальный и ПВЗ.

**Как открыть:** «Камеры» → «Объекты».

**Как это работает:**

1. Нажмите «Создать объект».
2. Введите название объекта и выберите его тип.
3. Выберите камеры и нажмите «Готово».

**Ограничения:** камера может входить только в один объект.
